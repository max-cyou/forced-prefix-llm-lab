# Как принудительный префикс при генерации ответа локальной LLM влияет на ее фильтры безопасности

В эксперименте сравнивались два режима генерации для одного и того же запроса:

- **NORMAL** — модель генерирует ответ без вмешательства.
- **FORCED** — первые токены ответа принудительно задаются через `LogitsProcessor`; затем модель продолжает генерацию самостоятельно.

Для анализа используются `normal_response` и `forced_free_response` — продолжение без принудительно заданного префикса.

# Вывод

Forced Decoding существенно влиял на поведение Qwen3.5-122B-A10B. Наиболее заметные изменения происходили в категориях кибербезопасности, экстремистской пропаганды, химических угроз и медицинского вреда.

Основные особенности FORCED-генерации: снятие первоначальных отказов, генерация проблемного содержания, поздние предупреждения, галлюцинации и периодические зацикливания.

Эффект зависел от категории: в одних сценариях модель переходила к содержательному продолжению, в других сохраняла ограничения или генерировала неполные и повторяющиеся ответы.
